Módulo 1 — Como a web funciona

Um site normalmente é formado por arquivos que o navegador interpreta. HTML organiza o conteúdo, CSS cuida da aparência e JavaScript adiciona comportamento.

  • HTML = estrutura
  • CSS = visual
  • JavaScript = interação

Módulo 2 — Primeiros passos com HTML

Crie um arquivo chamado index.html e comece com uma estrutura básica.

<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Meu site</title>
</head>
<body>
  <h1>Olá, mundo!</h1>
</body>
</html>

Módulo 3 — HTML semântico

Use elementos que explicam o papel de cada parte da página, como header, nav, main, section, article e footer.

<header>Cabeçalho</header>
<main>
  <section>Conteúdo principal</section>
</main>
<footer>Rodapé</footer>

Módulo 4 — CSS do zero

CSS permite definir cores, tamanhos, margens, bordas e muito mais.

body {
  font-family: Arial, sans-serif;
  background: #111;
  color: white;
}
h1 { font-size: 40px; }

Módulo 5 — Flexbox

Flexbox facilita o alinhamento de elementos em uma dimensão.

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 20px;
}

Módulo 6 — Grid e responsividade

Grid é ótimo para organizar blocos em linhas e colunas. Media queries permitem adaptar o layout a telas menores.

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
@media (max-width: 700px) {
  .cards { grid-template-columns: 1fr; }
}

Módulo 7 — JavaScript básico

JavaScript permite armazenar valores e executar ações.

const nome = "Aluno";
function saudacao() {
  alert("Olá, " + nome + "!");
}
saudacao();

Módulo 8 — DOM e eventos

Com o DOM, JavaScript pode encontrar elementos e modificar a página.

const botao = document.querySelector("#meuBotao");
botao.addEventListener("click", () => {
  document.body.classList.toggle("escuro");
});

Módulo 9 — Formulários

Formulários coletam informações. No lado do navegador, você pode validar campos antes de enviar.

<form>
  <input type="email" required>
  <button>Enviar</button>
</form>

Módulo 10 — Projeto completo

Agora junte estrutura, estilo e comportamento em uma landing page.

<h1>Meu projeto</h1>
<p>Uma página criada por mim.</p>
<button onclick="alert('Funcionou!')">Testar</button>

Módulo 11 — Publicando no GitHub Pages

Uma página estática pode ser hospedada em serviços de páginas estáticas. No GitHub Pages, coloque seu index.html no repositório e ative Pages nas configurações.
